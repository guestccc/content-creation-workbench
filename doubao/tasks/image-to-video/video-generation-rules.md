# 视频生成规则（权威源）

> 本文件是图片转视频任务的**唯一规则权威**。每次执行前必读。
> 进度状态读 `image-to-video-progress.json`，任务背景读 `README.md`。
> 最后更新：2026-09-19

---

## 一、输入与输出

- **输入**：`doubao/images/` 下的图片（9:16 竖版科普解剖图）。
- **输出**：`doubao/videos/` 下的视频。
- **画幅**：9:16，1080×1920。
- **模型**：固定用 `seedance_2.0_fast`（Seedance 2.0 Fast / Mini 轻量版），省额度。**不要**用 seedance_2.0 或 seedance_2.5（会员高级版，更耗额度）。
- **每张图片生成 1 段视频**，不要一张图出多段。

## 二、时长

- 目标时长：**3 秒**。
- ⚠️ 图生视频工具下限为 5 秒，无法直接出 3 秒。
- 当前方案：先出 **5 秒**样片给用户确认效果；用户要求严格 3 秒时，出 5 秒后用剪辑工具裁取前 3 秒。
- 执行前若用户已明确，按用户要求的最终时长走。

## 三、音频

- **完全无音频**：不配音、不旁白、不加 BGM、不加音效。
- 工具生成的画面为无声视频即可，不要额外配音轨。

## 四、视觉风格（本批统一）

> 本批（相机01~05、自动扶梯立体剖面图等）统一用此风格；新风格由用户另开新会话做，不沿用本规则。

核心思路：**让静态解剖图"活"过来，但只让内容主体动，背景和所有文字信息保持完全静止。**

### 4.1 运动范围（铁律：只动内容主体）

- **镜头固定不动**：不要推近、拉远、横摇、旋转，整个画布不位移、不变焦。
- **只有中央内容主体（被解剖的物体本身）微动**：如相机、扶梯、自行车、高铁等主体可以做极轻微运动。
- **必须静止的部分**：
  - 背景（米白底色、装饰星星等）
  - 主标题、副标题
  - 所有文字标签（部件名、说明小字）
  - 底部小贴士卡片、安全提醒卡片
  - 小插图、卡通人物（除非该人物就是内容主体）
- 目的：文字信息图必须始终清晰可读，动的只有"活的那台机器"。

### 4.2 内部微动（关键）

- 内容主体半透明外壳内的机械结构做**极轻微、缓慢**的运动：
  - **相机类（相机01~05）**：光圈叶片缓慢开合一次、快门一闪、镜头镜片轻微伸缩对焦。
  - **机械类（扶梯/自行车/高铁）**：齿轮慢转、链条走一格、履带缓行。
  - **空调类**：导风板轻微摆动，淡淡气流线示意。
- 动效要克制——是"剖面图活了"，不是"机器全速运转"。

### 4.3 不要做的

- **不要镜头推近/移动整个画面**（这是上一版样片的错误）。
- 不要让整个图片做 3D 翻转或视差倾斜。
- 不要让背景、标题、文字标签、底部卡片跟着动。
- 不要新增图片里没有的物体、文字或角色。
- 不要改变原图配色、画风、构图。

## 五、命名规则

- 输出文件名：`产品名 YYYY-MM-DD.mp4`
- 产品名取图片主名（去掉序号后缀时需和进度记录一致）。
- 示例：`相机 2026-09-19.mp4`、`自动扶梯 2026-09-19.mp4`。
- 若同日重名，加序号：`相机02 2026-09-19.mp4`。

## 六、执行前对账（必做第一步）

1. 扫描 `doubao/images/` 下全部图片（忽略 `.gitkeep`、`_*.md` 标记文件）。
2. 与 `image-to-video-progress.json` 对账：
   - 图在、记录为 done、对应视频仍在 videos/ → **跳过**。
   - 图在、记录为 done 但视频丢了 → 改回 pending 重生成。
   - 图在、json 里没有 → 追加 pending（其他会话新产的图）。
   - 图不在了、json 里有 → 标 `source_missing`。
3. 先报告对账结果（新增几张、跳过几张、待处理几张），再开始生成。

## 七、生成与回写

0. **每次只跑一个视频**：不要批量生成多张，不要一次把 pending 全跑完。生成一个、交付、等用户确认效果后，再跑下一个。省额度。
1. 按第四节风格写图生视频 prompt，调用图生视频工具，9:16，5 秒，模型 `seedance_2.0_fast`。
2. 视频保存到 `doubao/videos/`，按第五节命名。
3. 成功后更新三处：
   - `image-to-video-progress.json`：video 文件名、status=done、done_at=当天日期。
   - `进度总览.md`：对应行从待处理移到已完成。
   - `tasks/README.md` 当前进度表同步。
4. 失败：status=error，写明原因，不删半成品，等用户指示。

## 八、Prompt 模板参考

> 以图片为唯一参考，中文描述，强调"保持原图不变，只加缓慢推近和内部微动"。

通用骨架：
```
保持这张儿童科普解剖图完全静止：背景、主标题、所有文字标签、底部两张卡片、卡通人物和小插图都固定不动，镜头不推近不移动、不旋转。
只有画面中央的内容主体（被解剖的物体）做极轻微运动：【具体微动，如镜头光圈缓慢开合一次/齿轮慢转一格】。
其余画面元素一律保持原样，文字始终清晰可读，不新增任何元素，不加音效不加音乐，画面安静克制。
```
