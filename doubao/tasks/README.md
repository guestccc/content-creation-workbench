# tasks 目录（任务集合）

> 这里按**任务**分子目录存放。每个任务一个独立子目录，互不干扰。
> 新会话进来，先读本文件看有哪些任务，再进入对应子目录读它的 `README.md`。

## 目录约定

每个任务子目录建议包含：

| 文件 | 作用 |
| --- | --- |
| `README.md` | 任务背景、执行流程、进度表 |
| `*-rules.md` / `*-rules.md` | 该任务的权威规则 |
| `*-progress.json` | 机器可读的进度状态（权威源） |

## 任务清单

| 任务 | 目录 | 说明 | 状态 |
| --- | --- | --- | --- |
| 图片转视频 | [`image-to-video/`](./image-to-video/) | 把 `doubao/images/` 图片逐张生成视频到 `doubao/videos/`，跳过已完成项 | 进行中 |

## 新增任务

在本目录下新建一个子目录（用任务英文名，如 `xxx-yyy/`），里面放自己的 README、规则、进度文件，然后在上面表格登记一行。
