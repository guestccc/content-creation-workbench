# doubao（豆包素材目录）

存豆包相关的素材资源与规范文档。**资源本身不入库**（图片、视频体积大，
仓库放不下），只保留目录骨架与这份说明，新克隆下来能知道每段放什么。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `images/` | 豆包生成的图片素材 |
| `videos/` | 豆包生成的视频素材 |
| `specs/` | 提示词规范、生成参数、审核标准等文档 |

## git 规则

根目录 `.gitignore` 已配置：挡住 `doubao/` 下的资源文件，
放行 `README.md` 与各子目录的 `.gitkeep` 占位（git 不跟踪空目录）。
往里面扔素材不会被提交；如果要新增子目录，记得在 `.gitignore` 里
补一条放行规则。
